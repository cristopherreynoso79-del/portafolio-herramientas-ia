# Comandos que aprendí

| Comando | Para qué sirve |
|---|---|
| `pwd` | Mostrar la carpeta actual. |
| `ls -R` | Listar archivos y subcarpetas. |
| `cd carpeta` | Cambiar de carpeta. |
| `mkdir -p ruta` | Crear carpetas intermedias. |
| `touch archivo` | Crear un archivo vacío o actualizar su fecha. |
| `cp origen destino` | Copiar un archivo. |
| `cat archivo` | Mostrar su contenido. |
| `wc -l archivo` | Contar líneas. |
| `git init` | Crear un repositorio. |
| `git status` | Consultar cambios preparados y pendientes. |
| `git add archivo` | Preparar cambios para el commit. |
| `git commit -m "Mensaje"` | Guardar los cambios preparados. |
| `git diff` | Ver cambios sin preparar. |
| `git restore archivo` | Descartar cambios no preparados en un archivo seguido por Git. |
| `git log --oneline` | Ver una línea por commit. |
| `git log -1` | Ver el último commit con autor y fecha. |
| `git branch -M main` | Renombrar la rama actual a main. |
